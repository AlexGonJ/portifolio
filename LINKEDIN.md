• Animações: GSAP (GreenSock) com ScrollTrigger, Framer Motion e ScrollReveal

```text
Desenvolvimento de uma aplicação web de portfólio de alto padrão conceitual e técnico, focado em demonstrar a convergência entre design premium, interatividade rica em animações e performance otimizada para conversão de negócios.

O projeto foi concebido utilizando Next.js (App Router), React 19 e TypeScript para garantir uma arquitetura escalável e tipada. A interface visual conta com estilizações robustas mesclando Tailwind CSS v4 e SASS Modules, aplicando técnicas de layout responsivo fluido e temas dinâmicos.

No quesito de experiência visual e interativa, o projeto engloba:
- Renderização de Shaders WebGL customizados com Three.js e modelagem interativa via Spline, que reagem dinamicamente à interação física do ponteiro do mouse (mouse hover parallax e blur orgânico).
- Orquestração de animações complexas baseadas em scroll (como efeitos de cartas empilhadas em "Scroll Stack") e botões magnéticos interativos controlados via GSAP (GreenSock) e ScrollTrigger.
- Suporte a rolagem com efeito de inércia linear (Smooth Scroll) via Lenis.
- Mecanismo completo de internacionalização (i18n) em tempo de execução para suporte multilíngue (Português e Inglês).
- Foco em SEO técnico e performance (Core Web Vitals).
```
